# Third-party attributions

This library is original work, released under the MIT License (see `LICENSE`).

Three of the **CSS-only atoms** were adapted from community CSS idioms published on
[uiverse.io](https://uiverse.io) under the MIT License, then rewritten to the
`--site-*` theming contract used across this library:

- `ShineButton` — diagonal hover-sheen button idiom
- `GradientBorderCard` — rotating conic-gradient border idiom
- `HoverRollLink` — vertical text-roll link idiom

The remaining components are original implementations. Several encode common
editorial / scroll-animation *patterns* (sticky "selected work" galleries, velocity
marquees, dark↔light chapter inversions, etc.). Patterns are not copyrightable; no
third-party code was copied for those components.
